# Elementos-Transponibles-TEs-
En este repositorio encontraran el diseño e implementación en MongoDB de un modelo de datos que integra secuencias de elementos transponibles, metadatos taxonómicos y perfiles de k-mers procesados en Python sacados de unos archivos .Fasta y .csv los cuales contienen información de especies, familias, clases, secuencias de ADN, entre otros...
